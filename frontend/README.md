# Frontend — Bodega Demo

Interfaz web (React + TypeScript + Vite) del Sistema Integral de Bodega, Inventario y
Toma de Decisiones. Ver la documentación completa en [`../README.md`](../README.md) y
[`../docs/`](../docs/).

```bash
npm install
npm run dev     # http://localhost:5173, proxy /api -> http://localhost:4000
npm run build
npm run smoke   # recorrido end-to-end en navegador real (requiere backend+frontend arriba)
```
